Sao lưu & Khôi phục Lời chúc

Giữ nguyên toàn bộ lời chúc và hình ảnh của bạn khi thay code mới

Tự động lưu trên trình duyệt:

Mọi lời chúc bạn đăng đều đã được tự động lưu vào bộ nhớ trình duyệt (localStorage). Nếu bạn chỉ sửa/thay code trực tiếp trong cùng một file hoặc cùng trình duyệt, lời chúc sẽ tự động hiện lại! Ngoài ra, bạn có thể tải file sao lưu dự phòng bên dưới:

💡 Nếu bạn đã nhập 1 loạt lời chúc ở tab web cũ mà chưa kịp tải file lưu:

  1. Mở lại tab trình duyệt đang hiển thị các lời chúc cũ của bạn.
  2. Nhấn phím F12 (hoặc chuột phải chọn Inspect / Kiểm tra) ➡️ chuyển sang thẻ Console.
  3. Bấm nút Copy lệnh lấy dữ liệu bên dưới, dán vào Console của tab cũ rồi nhấn Enter:
copy(JSON.stringify(localStorage))

4. Sau khi nhấn Enter ở tab cũ, toàn bộ lời chúc + hình ảnh đã nằm trong bộ nhớ tạm (Clipboard). Bạn chỉ cần quay lại đây, bấm sang mục "2. Khôi phục / Nhập dữ liệu", dán (Ctrl+V) vào ô trống và bấm Khôi phục ngay là xong!

Đóng gói Web & Lấy link gửi cho gia đình

Lưu toàn bộ lời chúc & vị trí ảnh bạn vừa chỉnh vào 1 file duy nhất

✨ Cách đóng gói toàn bộ lời chúc đã nhập để đưa lên mạng cho mọi người xem:

  1. Bước 1: Tự thêm lời chúc, tải ảnh và kéo chỉnh khung ảnh vừa ý ngay trên trang này.
  2. Bước 2: Bấm nút "Tải file index.html (Đã nhúng sẵn lời chúc & ảnh)" bên dưới. Toàn bộ dữ liệu bạn vừa tạo sẽ được gắn cứng vào bên trong file này.
  3. Bước 3 (Đưa lên web miễn phí trong 30 giây):
    • Cách nhanh nhất (Kéo thả): Truy cập app.netlify.com/drop hoặc tiiny.host, kéo file index.html vừa tải thả vào là có ngay link gửi vào nhóm Zalo gia đình!
    • Firebase Hosting (`.web.app`): Đẩy file index.html lên Firebase Hosting để có link đuôi .web.app.
